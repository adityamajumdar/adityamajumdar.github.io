*Ongoing work with Amulya Yadav.*

Our [FAccT 2026 interview study](/projects/facct2026-hardness/) found that many AI for social impact projects fail because researchers and nonprofits begin with different assumptions about goals, data, timelines, and what success looks like. These mismatches usually surface months in, when they are expensive to fix.

This project tries to catch them earlier. We ran a focus group using speculative design, a method where participants react to imagined future scenarios, to map where early-stage collaborations tend to go wrong. From those sessions, we built a first version of a web-based scoping tool that walks both sides through the questions they should settle before any technical work begins.

We are now evaluating the tool against the Data Science for Social Good (DSSG) Project Scoping Worksheet as a baseline, using writing and reading tasks with study participants.
